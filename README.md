# 📦 Sistema de Gestão de Galpão (Logística)

Este projeto foi desenvolvido durante meus primeiros 7 dias de estudos em lógica de programação.

## 🚀 Funcionalidades
- Cadastro de lotes por nome, quantidade e valor.
- Cálculo automático do valor total do lote.
- Classificação de segurança: Lotes acima de R$ 5.000,00 são marcados como "Alto Valor".
- Interface interativa que permite múltiplos cadastros.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Portugol
- **Ferramenta:** Portugol Studio

## 📈 O que aprendi
Aprendi a estruturar variáveis, usar laços de repetição (`enquanto`), aplicar condições (`se/senao`) e realizar operações matemáticas para resolver problemas reais de logística.
